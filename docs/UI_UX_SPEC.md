# UI/UX Specification

## Design Goal
Create a modern, professional sustainability interface that feels like a real environmental technology product rather than a basic college form.

## Visual Direction
Clean, modern, minimal, professional and friendly. Avoid childish or overly decorative design.

## Home
Include:
- application name
- short description
- environmental sustainability message
- primary Calculate My Footprint action
- short explanation of carbon footprint
- calculator category overview

## Calculator
Organize inputs into clear sections:
1. Transportation
2. Electricity
3. Waste

Each section needs a heading, short explanation, labeled inputs, units and helpful hints where useful.

## Results
Show total footprint prominently, kg CO2e, category breakdown, chart, key observation, reduction suggestions and recalculate action.

## Form UX
Use clear labels, suitable input types, validation and units. Never rely on placeholder text as the only label.

## Error States
Use specific messages such as: "Enter a monthly electricity value greater than or equal to 0."

## Responsive Behavior
Desktop may use multi-column layouts. Mobile should stack sections, keep controls easy to tap, prevent horizontal scrolling and keep charts within the viewport.

## Accessibility
Use semantic headings, labels connected to inputs, keyboard navigation, visible focus indicators and sufficient contrast. Do not rely on color alone.

## Motion
Use subtle transitions only when useful and respect reduced-motion preferences where practical.

## Recommendations
Use constructive, non-shaming language based on the user's largest emission categories.
